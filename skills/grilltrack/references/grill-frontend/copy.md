# Copy

- Judge copy inside the accepted real layout with representative content
  lengths.
- Vary voice, structure, specificity, or information order materially.
- Preserve the selected layout and visual locks; do not let copy candidates
  silently redesign the page.
- Test overflow, truncation, wrapping, scanning, and responsive states.
- Wire both source fallbacks and content-managed values when the real product
  uses both, then verify the shipped path rather than only the picker bundle.
