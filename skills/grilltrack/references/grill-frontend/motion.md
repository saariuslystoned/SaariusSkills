# Motion

- Distinguish candidates by timing, choreography, emphasis, or interaction—not
  by arbitrary speed tweaks.
- Exaggerate evaluation variants only when clearly labeled; production tuning
  follows the lock.
- Replay only the active motion slot.
- Preserve scroll position before replay when it affects judgment.
- Honor reduced-motion preferences in production. An explicitly labeled test
  mode may override them only for evaluation.
- Verify motion in the rendered target browser, not only through computed
  values.
